# 小可 0.3.1 · 修复点击书本时人物变大

修复书本触摸的独立分支：此前点击头和脸已沿用正常人物帧，但点击书本仍切到头身比例不同的翻页素材。现在三处触摸都使用正常站姿或写字人物，仅播放触摸反馈。

增加真实鼠标按下/松开事件回归，覆盖空闲与工作时点击书本区域。141 项原生画布断言通过。保留 0.3.0 的通用 Agent 接入与素材缓存性能优化。

下载 `xiaoke-0.3.1-macos-arm64.zip`，退出旧版后替换「应用程序」中的 `小可桌宠.app`。Apple Silicon / macOS 13+；原存档和大小设置保留。

使用 `SHA256SUMS.txt` 校验下载包。本版本仍为 ad-hoc 本地签名，未通过 Apple 公证。安装与 Agent 接入详见仓库 README 和 docs/INSTALL.md。
