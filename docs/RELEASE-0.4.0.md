# 小可 0.4.0 · 全动作统一人物素材

统一站立、写字、走路、抱起、落地、日常、吃喝、睡姿和视线动作，共用同一角色设计与尺寸基准。站立也同步为新版，不再在静止时切回另一套人物。

移除旧头身分段拉伸，以及拖动缩小、落地压扁逻辑。抱起时双脚自然下垂，松手后其他动作保持同一用户缩放值。保留素材共享缓存，避免切页重新解码。

下载 `xiaoke-0.4.0-macos-arm64.zip`，退出旧版后替换「应用程序」中的 `小可桌宠.app`。Apple Silicon / macOS 13+。存档和用户大小设置保持兼容。仍为 ad-hoc 签名，未进行 Apple 公证。

生成源图、提示词和联系表随源码提供；素材由内置 imagegen 生成，脚本只做裁切、等比例缩放与排版。
