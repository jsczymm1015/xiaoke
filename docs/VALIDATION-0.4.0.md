# 0.4.0 统一动作验证

- 内置 imagegen 生成 5 组、160 帧源素材；整体替换小馆员基础动作、视线、生活、吃喝、工作与睡姿，素材和提示词可追溯。
- 透明间隙裁切、画布边界、动作行映射通过打包校验。每行只有固定的等比缩放系数，无头身分段拉伸；详见 artwork/measurements.json。
- 224 项原生画布断言通过，新增真实鼠标拖动/松手事件路径，以及 60%/100%/180% 下反复抱起、落地、喝水、进食、翻页、工作、静止的尺寸保持回归。
- 小馆员图集首次加载约 0.30 秒，1000 次共享缓存访问约 0.00057 秒（本机测量，非所有机器保证）。
- 实际 AppKit/SwiftUI 预览重新生成并检查，联系表涵盖各类动作；原有非视觉业务逻辑未改变。
- 构建、plist 和本地签名检查通过。仍未进行 Apple 公证。

数值基准保持头部在相同量级，坐姿自然变矮；头发、手臂和转头会改变可见轮廓，因此不把不同姿势描述为每个像素都完全相同。用户设置的 scale 和渲染矩形尺寸在动作之间保持一致。

实机验收：向屏幕内拖动 60px 后正常落地，再次拖回原位；核对存档中的大小设置始终不变。安装包与本机构建逐文件一致，窗口展示新版站立与落地素材。
